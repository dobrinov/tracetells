# Security

Please report vulnerabilities **privately**, never in a public issue or discussion. Use GitHub's private reporting on this repository: **Security → Report a vulnerability**.

That especially covers:
- anything that lets data identifying a person get past the collector's or the server's scrubbing
- authentication, two-step verification, sessions, invites or API tokens
- ways for one site, account or token to reach data it shouldn't

Include what you found, how to reproduce it and the version or commit. We'll confirm we received it and keep you updated until it's fixed.
