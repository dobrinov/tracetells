One loop, from behaviour to a shipped fix

  1. 01 Collect

    One script tag

    Clicks, rage and dead clicks, errors, scroll, forms. Single-page apps and full reloads.
  2. 02 Measure

    KPIs in your repo

    trace.json lives next to the code that sends the events, checked in CI.
  3. 03 Analyse

    Insights, not charts

    An analyst agent reads the aggregate digest and proposes changes with evidence.
  4. 04 Ship

    Copy as a prompt

    Each insight is a complete task for Claude Code, Cursor or any agent, via MCP too.
  5. 05 Evaluate

    Did it work?

    Before and after, with a significance test. Improved, regressed or no change.
Worry one: privacy

I'm not interested in your users. Only in patterns.

No session replay, no screenshots of your pages, no typed text. Trace sees that 18% of visitors tapped a product image and nothing happened, never who they were or what they typed.

How privacy works, in detail

Never collected

Input values, page titles, query strings, page content, recordings.

Scrubbed twice

Emails, cards, IBANs, tokens and phone numbers removed in the browser, then again on the server.

Your own rules

Admins mask elements, ignore pages and drop fields per website.

Tested with planted secrets

A leak page full of fake cards and passwords stores none of them.
Worry two: your website

Your visitors will never notice it.

The collector only takes notes while the page is busy, and does its work when the browser is idle. If anything inside it ever fails, the failure stays inside it.

Built for teams that ship with agents

KPIs as code

Define goals and events in trace.json, validate with trace check, publish with trace push. The dashboard only shows results. 
"checkout_conversion": {
  "from": { "pageview": "/checkout" },
  "to": { "pageview": "/checkout/success" },
  "goal": "increase", "target": "55%"
}

An MCP server, built in

Your agent reads KPIs, picks an insight, implements it and marks it released. Trace measures the impact. Aggregates only, scoped to one website. 
claude mcp add --transport http trace \
  https://app.tracetells.com/mcp

Works on any site

For one person or a company
